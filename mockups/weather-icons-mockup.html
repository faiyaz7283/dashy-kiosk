Dashy — Weather Icons Redesign (v3)

One-to-one mapping: every distinct OWM weather.main value gets its own unique icon. No grouping.

Changes from v2:
  • Added unique icons for ALL 15 OWM conditions: Drizzle, Mist, Haze, Smoke, Dust, Sand, Ash, Squall, Tornado
  • Removed grouping — each condition maps 1:1 to its own icon
  • Full mapping table showing OWM code ranges, current behavior, and new icon

2B. Day/Night Icon Variants

OWM icon codes have a d or n suffix (e.g., 01d = day, 01n = night). Key conditions have distinct day vs night appearances.

Day/Night Differentiation:
  • Clear: Sun (day) vs Moon with stars (night)
  • Clouds: Light grey cloud (day) vs Dark blue-grey cloud (night)
  • Rain/Drizzle/Thunderstorm: Lighter cloud (day) vs Darker cloud (night)
  • Snow: Light cloud (day) vs Dark cloud (night)
  • Mist/Fog/Haze: Lighter lines (day) vs Darker lines (night)
